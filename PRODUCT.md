# В команде

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Static HTML, CSS and JavaScript for this browser-local test page; implementation choice inferred from the request for a quick responsive demo.

## Users
New employees in warehouse, retail, sales and office roles at a sporting goods wholesale and retail company, plus HR staff, managers and mentors supporting their adaptation.

## Product Purpose
Help newcomers understand their work, complete short lessons and situational quizzes, find practical information, and ask a mentor for help.

## Operating Context
The company has around 400 staff, more than 100 hires annually, and uses Bitrix24 tasks for hiring and dismissal. No real company portal or employee data is available.

## Capabilities and Constraints
The current request is a working responsive simulation: on first visit create a fictional employee with first name, last name and a position. Four positions map to warehouse, retail, sales and office training bases. Profile-event and hiring-task input scenarios demonstrate the proposed Bitrix24 mapping with verified API notes. The local application creates the appropriate personal learning route and knowledge base. A deterministic chat assistant retrieves from that role's demo materials, with explicit handoff to a mentor. HR and managers see a seeded team plus newly created employees, real local progress, attempts, activity, support signals and mentor questions; replies are available to the employee. Browser storage is demonstration persistence, not a shared backend. No real Bitrix24 request, LLM request, external message, authentication or permissions enforcement is implemented or implied. Seeded people, activity and historical progress are clearly labelled as synthetic. The v3 data model preserves the earlier v1 data unchanged and imports a prior warehouse learner when available.

Use raised white panels on #f3f6fb, cobalt #315fe2 navigation/current states and orange #f58b46–#ed7734 primary actions, teal progress and completion, amber support signals, and stable profession colors. Preserve locally hosted Onest, the running-track signature, readable instructions, explicit simulation labels and mobile usability. The user additionally requested an orange/blue/white combination, transparent glass surfaces and animation across the interface. Use readable glass chrome with opaque fallback, one-time staggered reveals and interaction feedback, respecting reduced motion. The selected first page is now the normal setup page; remove the chooser and redirect historical study links to setup.

## Evidence on Hand
All people, training procedures, schedules and learning materials are synthetic. Training examples need company validation before real use.

## Product Principles
- One clear next step for the newcomer.
- Explain mistakes and allow another attempt.
- Keep mentor assistance easy to reach.
- Clearly identify demo data and local persistence.
